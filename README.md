
This Unity program is designed for tablets at a virtual reality equipment rental kiosk. 
It features at least two scenarios and several different states. In Scenario 1, the user encounters no issues, whereas in Scenario 2, the user faces a problem where their desired rental date is already booked, requiring them to choose a different day. 
The system includes states such as "Available," "Loaned," and "Charging," with each state triggering a different response; the user needs to know—based on the item they wish to rent—what type of situation they might encounter.

To install it, simply download it from GitHub, open Unity, and select the "SampleScene" scene, which is where absolutely everything is being saved.

Right now, its only limitation is that it lacks a database; consequently, your orders are not permanently saved, and the data is erased every time you return using the "Home" button.
